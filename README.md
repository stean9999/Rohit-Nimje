# 🎩 Monopolio Bank &bull; Digital Banker & Real Estate Manager

A digital companion web application for the **Monopolio — World Series With Adventure** international trade board game. It replaces physical paper cash with a banking dashboard, tracking accounts, property deeds, and transaction history.

---

## 🌟 Key Features

* **💰 Starting Bankroll ($7,000)**: Standard starting balance configured for all players with live total cash flow in circulation.
* **🏰 All 27 Board Properties**: Includes all 19 country properties, 4 transport systems (Railways, Roadways, Airways, Waterways), 2 utilities (Water Works, Solar Energy), and 2 Adventure Shortcuts (New Zealand, Australia) with exact board prices and authentic color groups.
* **🛡️ Zero-Negative Protection**: Automatically protects player balances from dropping below $0 during bank deductions, property acquisitions, and transfers.
* **⚡ Pass GO (+$2,500) & Taxes ($200)**: Instant 1-tap Pass GO celebration (with confetti and chime) and standard $200 Tax/Fine quick presets.
* **💵 Ascending Cash Note Stack**: Tap note chips ($200, $250, $300, $350, $400, $450, $500, $550, $600, $650, $700, $900, $950, $1,050) to quickly stack up rents or transactions.
* **📜 Master Ledger & Player Statements**: Full chronological transaction audit trail with player filtering, real-time search, and 1-click **Export to CSV**.
* **👑 Net Worth Tracker**: Calculates the true wealthiest player based on **Cash Balance + Property Assets**.
* **🔊 Pure Web Audio FX**: Realistic cash register chimes and audio feedback running 100% offline with zero external audio assets.

1. Clone this repository or download the source code:
   ```bash
   git clone https://github.com/stean9999/Rohit-Nimje.git
   ```
2. Simply double-click **`index.html`** in any web browser (Chrome, Edge, Firefox, Safari).
3. Works completely offline on desktop, tablets, and mobile devices!
